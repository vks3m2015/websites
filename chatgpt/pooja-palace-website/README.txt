POOJA PALACE WEBSITE
====================

Static responsive website for Pooja Palace banquet & event venue.

Highlights:
- Premium responsive design for desktop, tablet and mobile.
- Mobile-first refinements for navigation, hero, forms, booking process and gallery.
- Aesthetic responsive gallery with contained images, captions and full-screen lightbox.
- Two near-duplicate gallery photos removed to keep the gallery cleaner.
- Enquiry form opens WhatsApp with the visitor's event details.
- Google Maps directions link.

DEPLOYMENT
----------
Upload all files/folders in this directory to your hosting public_html (or equivalent) directory.
Make sure index.html is directly inside the web root.

No database or server-side runtime is required.

Logo
----
The website now includes the premium Pooja Palace logo in the header and footer, plus a favicon.
Logo files are stored in images/pooja-palace-logo.png and images/favicon.png.
